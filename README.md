# VelocePN Backend v2

## Установка

```bash
pip install -r requirements.txt --break-system-packages
```

## Настройка

В `bot.py` заполните:
- `BOT_TOKEN` — токен от @BotFather
- `PROVIDER_TOKEN` — токен ЮKassa (BotFather → Payments)
- `WEBAPP_URL` — ваша ссылка GitHub Pages
- `BACKEND_URL` — домен, где будет работать этот сервер (нужен HTTPS)

## Запуск

```bash
python bot.py
```

При первом запуске автоматически создастся файл `velocepn.db` (SQLite) со всеми таблицами.

## Добавление промокода (вручную, через консоль)

```bash
sqlite3 velocepn.db
INSERT INTO promo_codes (code, amount, max_uses) VALUES ('WELCOME300', 300, 100);
.quit
```
Это создаст промокод `WELCOME300`, который начисляет 300 ₽ на баланс и может быть использован 100 раз (по одному разу на каждого, кто его введёт).

## Что реализовано

| Функция | Endpoint |
|---|---|
| Создать счёт на тариф | `POST /api/create-invoice` |
| Создать счёт на пополнение | `POST /api/create-topup-invoice` |
| Проверить статус заказа | `GET /api/order-status` |
| Получить данные подписки | `GET /api/subscription` |
| Удалить устройство | `DELETE /api/devices/:id` |
| Баланс + история | `GET /api/balance` |
| Применить промокод | `POST /api/apply-promo` |

## Что ещё нужно доделать (заглушки)

1. **`generate_vless_config()`** — сейчас возвращает фейковую ссылку.
   Нужно подключить к API вашей панели 3x-ui: при оплате запрос должен
   создавать нового клиента в inbound и возвращать настоящую `vless://` ссылку.
2. **`trafficUsedGb`** — сейчас всегда 0, реальный расход трафика нужно
   подтягивать с сервера (у 3x-ui это тоже есть в API).
3. **Семейный тариф на несколько человек** — сейчас лимит устройств привязан
   к одному Telegram-аккаунту (владельцу подписки). Если нужно, чтобы разные
   члены семьи заходили под своими Telegram-аккаунтами — это отдельная
   доработка (нужно продумать приглашения в подписку).

## Важно

- `velocepn.db` — это файл на диске сервера. Делайте бэкапы регулярно,
  особенно перед обновлением кода.
- Не публикуйте `BOT_TOKEN` и `PROVIDER_TOKEN` в открытом репозитории.
